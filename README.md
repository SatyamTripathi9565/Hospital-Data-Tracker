# 🏥 Hospital Data Tracker – Power BI Dashboard

An interactive healthcare analytics dashboard built using Power BI to monitor hospital performance, patient statistics, treatment insights, and operational trends. This project helps visualize important healthcare KPIs for better decision-making and reporting.

---

## 📌 Project Overview

The Hospital Data Tracker Dashboard provides a complete overview of hospital-related data through dynamic visualizations and insights. It is designed to help users analyze:

- Patient records
- Admission trends
- Doctor performance
- Department-wise statistics
- Treatment and billing analysis
- Overall hospital operations

This dashboard transforms raw healthcare data into meaningful business insights using Power BI visualizations and data modeling techniques.

---

## 🚀 Features

- 📊 Interactive Power BI Dashboard
- 🏥 Department-wise Analysis
- 👨‍⚕️ Doctor & Patient Insights
- 💰 Billing and Revenue Tracking
- 📅 Admission & Discharge Trends
- 🔍 Dynamic Filters and Drill-down Analysis
